# Regla de Actualización Continua del Skill de CRM

Cada vez que se realice un cambio, mejora, corrección de bug, nuevo endpoint, modificación de prompts del agente IA de Gemini, cambio de variables de entorno o ajuste en la base de datos y permisos del CRM en este proyecto:

1. **Actualizar el Skill:**
   Se debe actualizar inmediatamente el contenido correspondiente en la carpeta del Skill:
   `C:\Users\USER\Desktop\ECOOMERCE\SKILLS ANTIGRAVITY\CRM Mensajes Alivperu\`
   (incluyendo `SKILL.md` y sus referencias en `references/`).

2. **Mantener la Coherencia Operativa:**
   Documentar nuevas rutas, variables o configuraciones operativas para que el usuario y cualquier agente futuro cuenten con el estado exacto del CRM en producción local.
